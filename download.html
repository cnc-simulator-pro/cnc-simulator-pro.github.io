What you get when you download CNC Simulator Pro

When you download CNC Simulator Pro from the official page you get the version 4 installer: the full program with the machine library, the virtual controller, SimCam CAD/CAM, tutorials and examples. Without a licence it runs as a trial; with one it becomes the paid edition, with no second download.

The page does not print a build number or the file size, so neither is given here. The same page offers the order link, the licence agreement you accept by installing, and two troubleshooting articles for plugin loading and graphics errors.

Before you install

Check two things first. Windows must be version 10 or later in 64 bit, and Microsoft .NET Framework 4.8 or higher must be present; current Windows 10 and 11 builds normally have it. Version 4 also leans on the graphics card, so a very old PC may struggle. The system requirements page has the full list and the fixes for common errors.

Install steps

  1. Check Windows and .NETConfirm Windows 10 or 11 in 64 bit and .NET Framework 4.8 or higher.
  2. Download the installerUse the Download now button on the official download page, not a mirror site.
  3. Run it and check the publisherIf the blue SmartScreen box appears, confirm the publisher is Zyntaxis, then choose More info and Run anyway.
  4. Start in trial modeOpen the program without a licence to use the trial.
  5. Activate after buyingChoose Help, then Activate License, and paste your code into the License string field.

The SmartScreen warning

Right after each release Windows or Edge may call the installer not commonly downloaded. The vendor explains that every new build starts with no reputation and the warning fades as more people install it. The file is signed in house, so the prompt should name Zyntaxis as publisher. If it names anyone else, stop and download again from the official page.

Older PCs and the trial

Below the main button the page offers legacy version 3.2 as a 32 bit installer for weak computers. It is lighter but no longer updated. The free trial page explains how the trial works and what happened to the old free licences, and the pricing page covers the licence options when you are ready to buy.

Frequently asked questions

Where is the safe place to download CNC Simulator Pro?

The official download page on cncsimulator.com. Its installers are signed by Zyntaxis, and Windows shows that name in the security prompt.

Why does Windows warn me about the installer?

New builds start without SmartScreen reputation, so Windows may call the file not commonly downloaded. If the publisher shown is Zyntaxis, choose More info and Run anyway.

Is a licence needed to install?

No. The program runs as a trial without a licence. You activate it later through Help, then Activate License.

How big is the installer?

The download page does not state the file size or the build number. Plan for a typical 3D program download and enough free disk space.

Can I install it on a 32 bit PC?

Not version 4. The page offers legacy version 3.2 as a 32 bit installer, but that version is no longer updated.
