CNC Simulator Pro system requirements and the common start up errors

The CNC Simulator Pro system requirements are short: 64 bit Windows 10 or later, .NET Framework 4.8 or higher and a reasonably modern graphics card. This page explains each item, the fallback for old PCs and the errors the support site documents.

Key facts

CNC Simulator Pro version 4 needs Windows 10 or later in 64 bit and Microsoft .NET Framework 4.8 or higher. The vendor recommends a modern processor and graphics card because version 4 draws detailed 3D scenes, and it lists a live internet connection as required. Why the graphics card matters most

Version 4 renders materials, chips and effects in 3D, and the help desk says it needs a fairly modern computer with a decent graphics card to work well. A strong processor with an old integrated graphics chip is the setup most likely to disappoint.

On laptops with two graphics chips, make sure the program uses the dedicated one. The free trial is the safe way to find out before paying, since it is the same program as the licensed edition.

If your PC is too old

The vendor keeps legacy version 3.2 on the download page for computers with a 32 bit processor, limited graphics or little memory. It runs better on such hardware but receives no updates, and features added in version 4 are missing. Use it as a stopgap for a classroom with old machines, not as a long term plan.

There is no macOS or Linux installer. If your team works on Macs, the comparison with CAMotics covers a free simulator that runs on all three systems.

Common errors and where the fixes are

The download page links two troubleshooting articles from the vendor's support portal. Both are worth reading before opening a ticket.

  • Graphics errors in version 4.0 and later: usually linked to the graphics driver or an older card. Start by installing the current driver from the card maker, then follow the vendor's article.
  • Plugin loading error: the vendor has a dedicated article on fixing it; a missing or outdated .NET Framework is a common cause on Windows to check first.
  • SmartScreen blocks the installer: normal for a new build. Check that the publisher is Zyntaxis, then choose More info and Run anyway.
  • Still stuck: the support portal lists known issues and lets you open a ticket.

Frequently asked questions

Does CNC Simulator Pro run on Windows 11?

Yes. The download page lists Windows 10 or higher in 64 bit, which includes Windows 11. Microsoft .NET Framework 4.8 or higher is also needed.

Can it run on a Mac or Linux?

There is no macOS or Linux installer. You would need a Windows installation on that machine or a cross platform simulator instead.

How much RAM does it need?

The vendor does not state a memory minimum for version 4. It says a fairly modern computer with a decent graphics card is needed, and points low memory PCs to legacy version 3.2.

Does it need an internet connection?

The vendor's about page lists a live internet connection as required. Plan for this on workshop PCs that are normally kept offline.

What causes graphics errors in version 4?

Version 4 is more demanding on the graphics card, and outdated drivers or old cards are the usual suspects. The vendor's support portal has an article on graphics errors in version 4.0 and later.
